# Feeding Jobs Website

Web application that helps users collect and manage job listings efficiently. The application retrieves job data from JobStreet based on user-defined keywords and displays the results in an organized, searchable dashboard. Users can filter job listings to quickly find relevant opportunities, manually add new jobs, edit existing records, delete outdated entries, and export the data to Excel for reporting or offline analysis. The system is designed to simplify job tracking and improve productivity by centralizing job information in a single platform.
